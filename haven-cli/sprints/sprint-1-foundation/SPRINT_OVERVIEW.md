# Sprint 1: Foundation & Core Infrastructure

## Sprint Goal
Establish the foundational infrastructure required by all other components. This includes database setup, configuration management, and core utilities.

## Duration
2 weeks

## Dependencies
None - this is the foundation sprint

## Sprint Deliverables
1. Working SQLite database with schema
2. Functional configuration system with file persistence
3. Video metadata extraction utilities
4. pHash calculation implementation
5. Core logging infrastructure

## Definition of Done
- All database models created and migrations working
- Configuration can be loaded, saved, and validated
- Video files can have metadata extracted and pHash calculated
- Unit tests passing for all components
- Code reviewed and merged to main branch

## Tasks in This Sprint
1. `task-01-database-setup.md` - Database Infrastructure (Backend Dev)
2. `task-02-config-persistence.md` - Configuration System (Backend Dev)
3. `task-03-video-metadata.md` - Video Metadata Extraction (Media Dev)
4. `task-04-phash-implementation.md` - Perceptual Hash Calculation (Media Dev)
