# Sprint 2: JS Services Integration

## Sprint Goal
Complete the JavaScript runtime integration for browser-dependent SDKs (Lit Protocol, Synapse). This enables encryption and Filecoin upload functionality.

## Duration
2 weeks

## Dependencies
- Sprint 1: Foundation (config system for API keys/endpoints)

## Sprint Deliverables
1. Working Lit Protocol encryption/decryption
2. Working Synapse SDK for Filecoin uploads
3. Fully functional JS Runtime Bridge
4. Download functionality from Filecoin

## Definition of Done
- Can encrypt data using Lit Protocol with access conditions
- Can upload files to Filecoin and receive CID
- Can download files from Filecoin by CID
- JS Runtime starts reliably and handles errors gracefully
- Integration tests passing
- Code reviewed and merged to main branch

## Tasks in This Sprint
1. `task-01-lit-protocol-integration.md` - Lit Protocol SDK Integration (Web3 Dev)
2. `task-02-synapse-sdk-integration.md` - Synapse/Filecoin Integration (Web3 Dev)
3. `task-03-js-bridge-improvements.md` - JS Runtime Bridge Hardening (Backend Dev)
4. `task-04-download-implementation.md` - Download from Filecoin (Backend Dev)
